Install

Requires Python 3.11. The package ships with activation, a licence check and the CLI.

# activate once
python3 activate.py VIBO-XXXX-XXXX-XXXX-XXXX
python3 check_license.py || exit 1

# remember something
vibo add "client anna" "pays on the 1st, PDF invoices"
vibo find "invoice terms anna"

# what it saved
vibo usage

The free open protocol is listed as Agent Memory Protocol on Agensi.
